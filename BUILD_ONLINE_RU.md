# Как получить готовый JAR без установки Gradle

1. Создай аккаунт на GitHub, если его ещё нет.
2. Открой https://github.com/new и создай репозиторий (например, `MegaRusHack`). Можно выбрать Public или Private.
3. В созданном репозитории нажми **Add file → Upload files**.
4. Распакуй этот ZIP на компьютере и загрузи **содержимое папки MegaRusHack_fixed** в репозиторий, включая папку `.github`. Важно: загружай файлы и папки проекта, а не сам ZIP.
5. Нажми **Commit changes**.
6. Открой вкладку **Actions**, выбери workflow **Build MegaRusHack**, затем **Run workflow** (если сборка ещё не запустилась автоматически).
7. Дождись зелёной галочки. Открой завершённый запуск и внизу страницы скачай артефакт **MegaRusHack-JAR**.
8. Распакуй скачанный артефакт ZIP. Файл `.jar` положи в `%AppData%\\.minecraft\\mods`.
9. Запускай Minecraft Java **1.21.10** с Fabric Loader и установленным Fabric API.

Если сборка завершилась красным крестиком, открой её и пришли мне текст ошибки из шага **Build mod** — тогда я смогу поправить проект.

## Что сейчас реализовано
Это клиентский каркас GUI: Right Shift открывает меню, ЛКМ переключает демонстрационные пункты, Esc закрывает меню. ElytraFly, Phase и BoatDisabler в проекте не реализованы; этот архив не добавляет такие функции.
