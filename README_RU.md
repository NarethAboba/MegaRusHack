# MegaRusHack — Fabric 1.21.10

Текущий архив содержит отдельные `MegaRusHack.java` и `ClickGui.java`, неоновый интерфейс с анимацией появления и рендер PNG-персонажа.

## Требования
- JDK 21
- Minecraft Java 1.21.10 и Fabric Loader
- Fabric API версии, указанной в `gradle.properties`

## PNG персонажа
Создайте папку `src/main/resources/assets/megarushack/textures/gui/` и положите туда файл `waifu.png`.
Код ожидает текстуру 128×192 пикселя; другой размер можно использовать, если изменить `textureWidth` и `textureHeight` в `ClickGui.java`.

## Управление
- Правый Shift — открыть/закрыть меню
- ЛКМ по строке — переключить демонстрационный модуль
- Esc — закрыть меню

## Важно
В исходном архиве отсутствуют классы `ElytraFly`, `Phase` и `BoatDisabler`, поэтому их нельзя проверить или исправить по этому исходнику. Здесь намеренно не реализованы обходы античита и скрытые игровые преимущества. Каркас предназначен для проверки GUI и структуры проекта.
